🤖 RAG Technical Assistant

Upload technical documents, ask questions and get answers grounded in your files with cited sources.

What this project demonstrates

RAG LLMs LangChain ChromaDB FastAPI Vector Search

This project demonstrates how to build a retrieval-augmented generation assistant that can answer domain-specific questions from technical documents — a high-demand skill in Applied AI.

Architecture

PDF Upload → Chunking → Embeddings → Vector DB → Query → Retrieved Context → LLM Answer + Citations

Quick Start

git clone https://github.com/Brunnobach/rag-technical-assistant.git
cd rag-technical-assistant
pip install -r requirements.txt
python src/ingestion/ingest.py
streamlit run app.py
