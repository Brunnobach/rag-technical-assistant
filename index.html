What this project demonstrates

This is a complete, production-oriented RAG pipeline designed for Solutions Architect and Applied AI portfolios. It shows how to turn static technical documents into a queryable knowledge base without relying on proprietary APIs.

📄 PDF Ingestion

Upload PDFs via REST API; text is extracted, chunked and embedded automatically.

🔍 Semantic Search

sentence-transformers power dense retrieval against a persistent ChromaDB collection.

✅ Cited Answers

Every answer includes the source document, chunk index, page and similarity score.

🐳 Cloud Ready

Containerized with Docker Compose and automated tests in GitHub Actions.

Architecture

PDF Upload → Text Extraction → Chunking → Embeddings → ChromaDB → Query → Retrieved Context → Answer + Citations

Key Features

  • FastAPI endpoints: /upload, /query, /health, /reset
  • Chunked embeddings with configurable size and overlap
  • Vector storage backed by ChromaDB, running as a Docker service
  • No OpenAI API key required; uses open-source sentence-transformers
  • Deterministic fallback answer generation plus optional local LLM support
  • Comprehensive pytest suite and GitHub Actions CI/CD
  • GitHub Pages landing page for portfolio demos

Quick Start

git clone https://github.com/Brunnobach/rag-technical-assistant.git
cd rag-technical-assistant

# Run with Docker Compose
docker compose up --build

# Upload a PDF and query via curl
curl -X POST -F "file=@document.pdf" http://localhost:8000/upload
curl -X POST http://localhost:8000/query \
  -H "Content-Type: application/json" \
  -d '{"question":"What does this document say?"}'
